# Reference

Use these pages when you know what you want to look up:

- [API](api.md): public classes, methods, functions, parameters, and attributes.
- [Options](options.md): Confidantic-specific controls and relevant inherited defaults.
- [Annotations](annotations.md): parsing and construction annotations grouped by purpose.

If you are choosing an approach, start with [configuration and objects](../concepts/configuration-and-objects.md).
For a working application, follow [getting started](../getting-started/first-application.md).
The [wiki](https://github.com/sztal/confidantic/blob/master/wiki/README.md) contains
the deeper implementation reference, including private modules.
